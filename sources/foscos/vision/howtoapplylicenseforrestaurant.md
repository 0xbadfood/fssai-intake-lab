# How to apply for a license for Restaurant?

**Step 1:** Refer to How to apply for license /registration manual for creating a license/registration

**Step 2:** Click on License/Registration and Apply for License/Registration on the yellow Menu box.

[Image of a web form interface. The form has a blue background. On the left, there are fields: 'Enter Application Reference No.' with a text input box, 'Enter Captcha Code' with a text input box, and a captcha image showing '808846' with a refresh icon. Below these is a 'Submit' button. On the right, there is text: 'Filling Application for Registration becomes easier through App. Remain updated with FSSAI news. To download 'Food Safety Connect' App.Scan the below QR' followed by a QR code. Below the main form area, there are five colored boxes with icons and text: 1. Orange box: 'Apply License/Registration Fee: Rs.100 to 7500 per year'. 2. Green box: 'Modification of License and Registration Fee: Rs.1000 for License Rs.100 for Registration'. 3. Blue box: 'Renewals Fee is same as of new License and Registration. Can be applied as early as 180 days prior to expiry date'. 4. Light blue box: 'Food Consumer Grievance'. 5. Dark blue box: 'File Express Annual Return'.]

**Step 3:** Select the State and Read the Note before proceeding.

[Image of a web form section. The section is titled 'Select Kind of Business'. Below this, there is a light orange box containing the text: 'Select the state where premises is located for which License/Registration will be obtained.' followed by a dropdown menu labeled 'Select State'. Below this, there is a note in red text: 'Note: Each location will be issued separate license (except transporter where one license will be issued for all vehicle of a single transporter/ business). In case FBO is operating in more than one state, he has to obtain one additional Central License for Head office/ registered office and separate license for each location as per Capacity/Turnover (State/ Central License)'. Below the note, there is text in blue: 'A Food Business Operator (FBO)'s premise shall have only one FSSAI License or Registration on which any number of kind of businesses (KoB) can be endorsed.' There is a vertical blue line on the left side of this section.]

**Step 4:** Read the Group Heads of Kind of Business. Select Restaurant from food services Business Group Head.
