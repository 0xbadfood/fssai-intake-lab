Part-A) Updating PAN while <mark>renewal</mark> of license in FBO login

1.. After logging into the FBO's Foscos account, the user should click on the "Renewal" tab located on the right side of the screen, then select the "Proceed" button as shown below.

[Image of a web interface showing a dashboard with a left sidebar menu. The menu item "Apply for Renewal of License / Registration" is highlighted with a red box. The main content area shows a table under "License" with columns: S.No, License No./Reference No., Company Name, Issue Date, Expiry Date, License Category, KCB, Action. A row is visible with data, and the "Proceed" button in the Action column is highlighted with a red box.]

2.. Clicking on the "Proceed" tab will open the following window, which provides the option to update the "PAN," as shown below.

[Image of a web form titled "Fill Application Details". The form has tabs: Premises Detail, Product Selection, Communication Details, Required Document, Payments. The "Premises Detail" tab is active. Fields visible include: Name of Company/Organization, Address of Premises for which license is being applied (with sub-fields for Address, State, District, Pincode, Sub-District), GST No. (if any), and PAN No. The "PAN No." field is highlighted with a red box and an arrow pointing to it with the text "PAN can be updated here".]

Part-B) updating PAN during **modification** of license

1.. After logging into the FBO's FoscOS account, the user should click on the "Modification" tab located on the right side of the screen, then select the "Proceed" button as shown below.

[Screenshot of FoscOS dashboard. Left sidebar menu includes: Dashboard, License/Registration, Renewal, Modification (expanded to show: Apply for Modification in License / Registration, Status of Non Form C Modification, Surrender / Transfer, Food Consumer Grievance, Annual Return, Inspection, Quarterly Return for Exporters, Audit Management, Hygiene Management, Help, Six Monthly Lab Testing Report, Recall Of Food Items Near Expiry/Expired, Improvement Notice, Adjudication, Pay Penalty, Food Office License, Tax Invoice, Ref/Debtor NOC Application, File your response). Main content area shows 'Apply for Modification' with 'License' and 'Registration Certificate' sections. A table under 'License' has columns: S.No., License No./Reference No., Company Name, Issue Date, Expiry Date, License Category, More, Action. One row is visible with 'Proceed' button highlighted in red.]

Clicking on the "Proceed" tab will open the following window, which provides the option to update the "PAN ," (under Premises Detail) as shown below.

[Screenshot of 'Fill Application Details' form. Top banner: 'Form 'B' : Application for License / Renewal of License under Food Safety and Standards Act, 2006'. Tabs: Premises Detail (active), Product Selection, Communication Details, Required Document, Payments. Form fields visible: Name of Company/Organization*, Address* (with sub-fields: Address, State, District, Pincode, Sub-District, GST No. (If any), CIN No. (If any), PAN No.*). A red box highlights the 'PAN No.*' field with a note 'PAN can be updated here'. Bottom buttons: Save & Next, Cancel. Note at bottom: 'Note: The above information will be printed on the license; make sure there is no typo/mistake. Once you click on Save & Next button your information will be saved and in case you exit the system you can continue the submission process from the list of incomplete applications on Home page.']
