**The User manual of Apply and Generate License/Registration:-**

**Note:-Apply and Generate the License/Registration provided by FoSCoS for Central authorities and State authorities - the flow will be the same as shown below**

**Step 0:** Authorities can log on to this URL https://foscos.fssai.gov.in on the web browser. Sign in using your username and password.
